# /retro [scope]

`scope` ∈ `daily` | `weekly` | `monthly`. Default: `weekly`.

## Procedure

### 1. Determine the window

- `daily` — the last 24 hours of commits, agent transcripts, and gate envelopes.
- `weekly` — the last 7 days. This is the flagship retro; it typically fires Friday afternoons via the launchd job (`pe launchd`).
- `monthly` — the last calendar month. Used for higher-level pattern recognition (which gates keep tripping, which agents keep escalating).

### 2. Collect the raw inputs

- `git log --since="<window>" --numstat` — commit velocity + churn hotspots.
- `.pe/decisions.jsonl` (last N lines within window) — shadow-mode router decisions + which failure_class fired most.
- `.pe/reconciliations.jsonl` — join actual outcomes to shadow decisions; catches router miscalibration.
- `.claude/gates/*.json` — envelope verdict distribution (PASS/WARN/FAIL rates).
- `docs/dev-log/daily/*.json` or `weekly/*.json` — if the project has the dev-log collector (auto-generated by `scripts/run_daily.sh` in some adopters).

### 3. Invoke `retrospective-agent`

Pass:
- The window bounds.
- The raw input paths above.
- A note on what the operator wants surfaced (e.g. "focus on TDD adherence" or "focus on token cost").

### 4. Expected output

The retro report should include:

- **Velocity delta** — commits per day vs the previous window.
- **Gate verdict distribution** — PASS/WARN/FAIL counts + trend.
- **Router miscalibration** — where the shadow router's action disagreed with the operator's actual choice.
- **Recurring mistakes** — findings that appear ≥3 times across gates in the window (candidates for `/skill` promotion or CLAUDE.md rule additions).
- **Churn hotspots** — files touched more than N times (candidates for refactor).
- **Skill / rule / agent proposals** — one concrete change the operator can approve to prevent the top recurring mistake.

### 5. Persist

Save the report to `docs/dev-log/retro-YYYY-MM-DD-<scope>.md`. Do NOT
auto-commit it — the operator reviews and commits manually.

## Related

- `agents/retrospective-agent.md` — the agent that does the analysis
- `templates/retro.md` — canonical retro template
- `pe launchd` — wires the weekly retro fire on macOS

## Notes

The retrospective-agent depends on inputs the engine doesn't yet
always ship (dev-log collector). If the dev-log directory is absent,
degrade gracefully: derive velocity + churn from `git log --numstat`
alone, and note the degradation in the report so the operator knows
what was missing.
